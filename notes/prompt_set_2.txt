# SET 2 — Overview, Botanical Descriptions, Identification, Morphology, Anatomy & Microscopy

This set supplies the data needed to describe medicinal plants accurately and help users identify them. It covers:

- General botanical descriptions
- Morphological characteristics
- Diagnostic identification features
- Plant organs and anatomy
- Microscopic characteristics
- Botanical illustrations and photographs
- Identification keys
- Herbarium specimens
- Botanical terminology and descriptive standards

**Important distinction:** Unlike taxonomic datasets, botanical descriptions are often distributed across regional floras, scientific publications, herbarium records, and specialized databases. There is no single comprehensive, freely downloadable global dataset containing all these features for every plant.

The most effective strategy is to combine global botanical databases, regional floras, specimen repositories, trait datasets, and specialized anatomical resources.

## 3. TRY Plant Trait Database — Quantitative and qualitative plant traits

TRY Plant Trait Database

This is particularly valuable if your SQL schema will contain standardized plant characteristics.

### What it contains
TRY aggregates plant traits from hundreds of datasets, including published and unpublished observations.

The traits include:

| Category | Examples |
|---|---|
| Morphology | Plant height, leaf area, leaf dimensions |
| Anatomy | Leaf anatomical characteristics |
| Phenology | Flowering time, leaf persistence |
| Physiology | Photosynthetic characteristics |
| Biochemistry | Plant chemical characteristics |
| Ecology | Growth form, woodiness, habitat-related traits |
| Functional traits | Specific leaf area, leaf mass, seed mass |

TRY Version 7, released in September 2026, reports approximately **22.86 million trait records and 306,701 plant taxa**. [try-db.org](https://www.try-db.org/?utm_source=chatgpt.com)

### Access
- **Database:** [TRY Database](https://www.try-db.org/?utm_source=chatgpt.com)
- **Data portal:** [TRY Data Portal](https://www.try-db.org/TryWeb/Database.php?utm_source=chatgpt.com)

### Downloading
TRY provides data requests and downloads, but access to particular datasets or bulk exports can involve registration, request workflows, and dataset-specific terms.

### Recommendation
Use TRY for quantitative trait data—not as a substitute for a complete botanical description.

**Critical:** Store each trait as an observation with its original unit, value, source, measurement context, and uncertainty. Do not collapse multiple measurements into a single supposedly definitive species value.

# 14. Important design decision: preserve original descriptions

For a consensus botanical website, I recommend keeping **two separate layers**:

1. **Source layer:** Original descriptions, original measurements, original terminology, original citations.
2. **Normalized layer:** Your standardized descriptions and trait values, mapped into your own botanical vocabulary.

For example, three floras might describe a leaf as:

- Ovate
- Broadly ovate
- Egg-shaped

You can normalize these into a common controlled vocabulary, but preserve each original statement and its source.

This gives you:
- Traceability
- Reliable citations
- A way to resolve disagreements
- Better future updates
- Ability to display multiple authoritative descriptions
- Machine-readable botanical characteristics

For images, preserve the original attribution and license at the individual image level—not merely at the dataset level.
