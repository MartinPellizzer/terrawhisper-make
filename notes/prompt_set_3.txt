# SET 3 — Distribution, Geography, Habitat, Ecology & Environmental Conditions

This set covers the resources you'll need to describe **where medicinal plants occur, where they are native or introduced, which environments they inhabit, and what ecological conditions influence their growth**.

For a global medicinal plant database, this is particularly important because a species may have:
- A native distribution
- Introduced populations
- Naturalized populations
- Cultivated populations
- Invasive populations
- Different ecological requirements across its range

**Key recommendation:** Never represent a plant's distribution using only one geographic field. Native range, observed occurrence, cultivation, naturalization, and invasion should be separate concepts.

I'll distinguish downloadable datasets, APIs, authoritative reference databases, and resources that are primarily online.

# PART I — Plant distribution and geographic range

## 1. GBIF — Global Biodiversity Information Facility

**The most important global source for observed plant occurrences.**



### What it contains
GBIF aggregates occurrence data from:
- Herbarium specimens
- Botanical collections
- Museum collections
- Biodiversity monitoring
- Citizen science observations
- Research projects
- Environmental surveys

You can obtain:
- Latitude and longitude
- Country and locality
- Collection date
- Scientific name and identification
- Basis of record
- Institution and collection
- Collector
- Identification history
- Associated photographs and media
- Dataset provenance

### Download and API
- **Portal:** [GBIF](https://www.gbif.org/?utm_source=chatgpt.com)
- **Occurrence downloads:** [GBIF Occurrence Download](https://www.gbif.org/occurrence/download?utm_source=chatgpt.com)
- **API documentation:** [GBIF Occurrence API](https://techdocs.gbif.org/en/openapi/v1/occurrence?utm_source=chatgpt.com)
- **Bulk download documentation:** [GBIF API Downloads](https://techdocs.gbif.org/en/data-use/api-downloads?utm_source=chatgpt.com)

GBIF supports authenticated, asynchronous bulk occurrence downloads in CSV and Darwin Core Archive formats. [techdocs.gbif.org](https://techdocs.gbif.org/en/openapi/v1/occurrence?utm_source=chatgpt.com)

### License
Occurrence records may have CC0, CC BY, or CC BY-NC licenses. Each record and associated media must be checked independently. [gbif.org](https://www.gbif.org/publishing-data?utm_source=chatgpt.com)

### How to use it
For every medicinal plant, retrieve its occurrence records and construct:
- Observed distribution maps
- Geographic occurrence summaries
- Regional presence
- Historical occurrence timelines
- Collection density maps

**Important:** GBIF occurrences are not equivalent to a species' true geographic range. Sampling bias, misidentification, cultivated specimens, and geographic gaps can distort maps.

## 2. POWO / WCVP — Native and introduced distribution

### What it contains
Kew's World Checklist of Vascular Plants (WCVP), used by POWO, provides authoritative geographic distribution information for accepted vascular plant taxa.

It distinguishes:
- Native distributions
- Introduced distributions
- Geographic regions
- Subregional distributions

POWO represents distributions using narrative descriptions and TDWG geographical codes, generally at the third geographical level. [Plants of the World Online](https://powo.science.kew.org/about-wcvp?utm_source=chatgpt.com)

### Access
- **POWO:** [Plants of the World Online](https://powo.science.kew.org/?utm_source=chatgpt.com)
- **WCVP documentation:** [About WCVP](https://powo.science.kew.org/about-wcvp?utm_source=chatgpt.com)

### What you should extract
For each species:
- Native range
- Introduced range
- Region codes
- Geographic narrative
- Source/reference
- Taxonomic concept used

### Recommendation
Use POWO/WCVP as a major source for **expert-compiled geographic range**, and GBIF for **individual observed occurrences**.

These are complementary data types.

### What it contains
The International Union for Conservation of Nature Red List provides:
- Species distribution maps
- Range polygons
- Point records for some taxa
- Geographic range metadata
- Threat status
- Population and habitat information
- Geographic assessment information

### Download
**IUCN spatial data:**

[IUCN Red List Spatial Data Download](https://nrl.iucnredlist.org/resources/spatial-data-download?utm_source=chatgpt.com)

Spatial data are available in:

- CSV point data
- Other group-specific geographic formats

IUCN reports that spatial data are available for more than 155,800 assessed species, although coverage varies considerably by taxonomic group. [nrl.iucnredlist.org](https://nrl.iucnredlist.org/resources/spatial-data-download?utm_source=chatgpt.com)

### License and limitation
IUCN spatial data are generally made available for non-commercial use under their terms. Commercial or other reuse may require additional permission. [nrl.iucnredlist.org](https://nrl.iucnredlist.org/resources/spatial-data-download?utm_source=chatgpt.com)

### Recommendation
Use IUCN range polygons for:
- Conservation-oriented maps
- Threatened medicinal plants
- Endemicity
- Geographic conservation assessments

Do not assume IUCN has range polygons for every medicinal plant.

# PART II — Habitat and ecological information

## 5. sPlotOpen — Global vegetation plots

**One of the best open resources for understanding plant communities and ecological habitats.**

### What it contains
sPlotOpen contains:
- Species composition of vegetation plots
- Plant abundance or cover information
- Plot coordinates
- Plot size
- Sampling dates
- Elevation
- Slope
- Aspect
- Biome
- Vegetation type
- Environmental information
- Plant functional traits

The open dataset contains **95,104 vegetation plots**, representing 42,677 vascular plant species, with plot records spanning 1888–2015. [iDiv](https://www.idiv.de/research/projects/splot/splotopen-splot/?utm_source=chatgpt.com)

### Download
- **Project:** [sPlotOpen](https://www.idiv.de/research/projects/splot/splotopen-splot/?utm_source=chatgpt.com)
- **Dataset DOI:** [sPlotOpen Dataset](https://doi.org/10.25829/idiv.3474-40-3292?utm_source=chatgpt.com)
- **Download repository:** [iDiv Data Portal](https://idata.idiv.de/?utm_source=chatgpt.com)

### What you can derive
For each medicinal plant:
- Plant communities in which it occurs
- Associated species
- Vegetation types
- Ecological context
- Elevation distribution
- Habitat associations
- Relative abundance in vegetation plots

### Recommendation
This is an excellent resource for building a **habitat association database**, rather than merely listing generic habitats such as forest or grassland.

Remember that vegetation-plot presence represents sampled ecological conditions, not necessarily the complete habitat range of a species.

## 6. EUNIS — European habitat classification

### What it is
EUNIS is a hierarchical habitat classification developed for harmonized habitat description and biodiversity assessment in Europe.

It covers:
- Forests
- Grasslands
- Heathlands
- Scrub
- Wetlands
- Inland waters
- Coastal habitats
- Rocky habitats
- Artificial habitats
- Marine habitats

### Download
- **Classification and datasets:** [EEA EUNIS Habitat Classification](https://www.eea.europa.eu/en/datahub/datahubitem-view/638330ea-90e6-4e41-81ea-e70f25ae7117?utm_source=chatgpt.com)
- **Classification documentation:** [EEA EUNIS Documentation](https://www.eea.europa.eu/en/datahub/datahubitem-view/1b87cddc-2593-40cc-a341-426246cc7c38?utm_source=chatgpt.com)
- **Habitat datasets:** [EEA Habitat Data Hub](https://www.eea.europa.eu/en/datahub/datahubitem-view/123d0c9a-a6fa-4f2d-b887-5d8e5468faed?utm_source=chatgpt.com)

The classification includes habitat codes, names, descriptions, and crosswalks to other habitat typologies. Tabular downloads are available in Excel formats. [eea.europa.eu](https://www.eea.europa.eu/en/datahub/datahubitem-view/638330ea-90e6-4e41-81ea-e70f25ae7117?utm_source=chatgpt.com)

### Recommendation
Use EUNIS as a controlled habitat vocabulary for European species.

You could build a table mapping:
`plant_species → habitat_code → source → confidence`

Do not automatically assume EUNIS codes apply globally. For worldwide coverage, map regional habitat descriptions to broader international classifications.

## 7. WWF Terrestrial Ecoregions

The WWF terrestrial ecoregion system is a widely used global biogeographic classification.

### What it contains
- Ecoregion polygons
- Ecoregion names
- Ecoregion codes
- Biogeographic descriptions
- Ecological characteristics
- Conservation context

### Access
- [WWF Ecoregions of the World](https://www.worldwildlife.org/publications/terrestrial-ecoregions-of-the-world?utm_source=chatgpt.com)
- [WWF GIS datasets](https://www.worldwildlife.org/publications/terrestrial-ecoregions-of-the-world?utm_source=chatgpt.com)

### What it is useful for
You can associate occurrence points or distribution polygons with:
- Tropical moist forests
- Tropical dry forests
- Mediterranean forests
- Temperate forests
- Boreal forests
- Grasslands
- Deserts
- Tundra
- Montane ecosystems

### Recommendation
Use ecoregions to contextualize a plant's geographic distribution.

For example:

> This species occurs in the Mediterranean Basin, particularly within Mediterranean forests, woodlands, and shrub ecosystems.

The ecological association should be supported by occurrence or ecological evidence rather than inferred solely from a broad range polygon.

# PART III — Climate, temperature, rainfall, and environmental conditions

These datasets are not botanical databases. They are environmental layers that you can intersect with validated plant occurrence records to estimate environmental conditions in which a species is observed.

This distinction is essential:

- A botanical source says where a plant occurs.
- A climate dataset says what the climate is at a location.
- A spatial analysis combines the two to estimate the climate associated with observed populations.

## 8. WorldClim — Global climate data

**One of the most important environmental datasets for your project.**

### What it contains
WorldClim provides global gridded climate data:

- Minimum temperature
- Mean temperature
- Maximum temperature
- Precipitation
- Solar radiation
- Wind speed
- Water vapor pressure
- Bioclimatic variables

It includes historical climate, future climate projections, and other climate products.

### Access
- **Official website:** [WorldClim](https://www.worldclim.org/?utm_source=chatgpt.com)
- **Historical climate:** [WorldClim Historical Data](https://www.worldclim.org/data/worldclim21.html?utm_source=chatgpt.com)
- **Future climate:** [WorldClim CMIP6](https://www.worldclim.org/data/cmip6/cmip6_clim30s.html?utm_source=chatgpt.com)

### Important variables
WorldClim's BIO variables include:

| Variable | Meaning |
|---|---|
| BIO1 | Annual mean temperature |
| BIO2 | Mean diurnal temperature range |
| BIO3 | Isothermality |
| BIO4 | Temperature seasonality |
| BIO5 | Maximum temperature of warmest month |
| BIO6 | Minimum temperature of coldest month |
| BIO7 | Annual temperature range |
| BIO8–BIO11 | Temperatures during selected quarters |
| BIO12 | Annual precipitation |
| BIO13 | Precipitation of wettest month |
| BIO14 | Precipitation of driest month |
| BIO15 | Precipitation seasonality |
| BIO16–BIO19 | Precipitation during selected quarters |

### Recommendation
Use WorldClim to calculate:
- Typical temperature ranges
- Annual precipitation
- Seasonal precipitation patterns
- Environmental conditions at occurrence locations
- Potential climate suitability analyses

For reproducibility, record the WorldClim version, spatial resolution, time period, and climate model used.

CHELSA V2.1 includes global kilometer-scale bioclimatic data and multiple climate products. [chelsa-climate.org](https://www.chelsa-climate.org/datasets?utm_source=chatgpt.com)

### Access
- **Official portal:** [CHELSA](https://www.chelsa-climate.org/?utm_source=chatgpt.com)

**Very useful for plant habitat and cultivation sections.**

SoilGrids provides global gridded soil information, including:

- Organic carbon
- Soil texture
- Sand content
- Silt content
- Clay content
- Bulk density
- Cation exchange capacity
- Nitrogen
- Soil depth-related properties

It provides predictions at multiple soil depths and spatial resolutions.

### Access
- **Official portal:** [SoilGrids](https://soilgrids.org/?utm_source=chatgpt.com)
- **ISRIC information:** [ISRIC SoilGrids](https://isric.org/explore/soilgrids/?utm_source=chatgpt.com)
- **REST API documentation:** [SoilGrids REST API](https://rest.isric.org/soilgrids/v2.0/docs?utm_source=chatgpt.com)

### Important current limitation
ISRIC reports that the SoilGrids REST API is temporarily paused due to service issues. Alternative data access methods are available, so do not make your production pipeline dependent on the API alone. [isric.org](https://isric.org/explore/soilgrids/?utm_source=chatgpt.com)

### Recommendation
Use SoilGrids to estimate:
- Soil pH associated with plant occurrences
- Soil texture
- Soil organic carbon
- Nutrient-related environmental context
- Potential soil preferences

**Do not write that a species prefers a specific soil simply because its occurrence points fall on that soil type.** Soil preference requires botanical or ecological evidence, ideally supplemented by statistical analysis.

# PART VI — SQL database architecture for distribution and ecology

I recommend separating **geographic range**, **occurrence records**, **habitat descriptions**, and **environmental observations**.

## 1. Geographic ranges

### `taxon_ranges`

| Field | Description |
|---|---|
| range_id | Internal identifier |
| taxon_id | Taxon |
| region_id | Geographic region |
| range_type | Native, introduced, naturalized, invasive, etc. |
| presence_status | Present, uncertain, extinct, etc. |
| source_id | Source |
| source_reference | Citation |
| confidence | Confidence level |
| valid_from | Beginning of validity |
| valid_to | End of validity |

### `geographic_regions`

| Field | Description |
|---|---|
| region_id | Internal identifier |
| region_name | Region name |
| region_type | Country, continent, TDWG region, ecoregion, etc. |
| parent_region_id | Hierarchical parent |
| region_code | Standardized code |
| geometry | Polygon, if applicable |

Do not force all geographic concepts into one hierarchy. Countries, TDWG regions, biogeographic realms, and ecoregions represent different systems.

## The most important conceptual distinction

For your future medicinal plant pages, I would display these separately:

**Distribution**
- Native range
- Introduced range
- Naturalized range
- Invasive range
- Cultivated distribution
- Observed occurrences

**Habitat**
- Published habitat descriptions
- Vegetation communities
- Habitat classifications
- Associated species

**Environmental requirements**
- Temperature
- Rainfall
- Elevation
- Soil
- Light
- Moisture
- Climate zone

**Ecological observations**
- Actual recorded environmental conditions
- Statistical summaries of occurrences
- Trait/environment associations
- Ecological modeling results

This will prevent your website from confusing observed distribution with ecological preference.
